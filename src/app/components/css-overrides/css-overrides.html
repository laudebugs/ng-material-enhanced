Custom Theme Color Palettes

Theme colors (such as _theme-colors.scss) are intentionally excluded from the generic component overrides so you can supply your own primary, secondary, and tertiary brand palettes.

Generate your custom Material 3 color palettes using the official Angular Material schematic: 

ng generate @angular/material:theme-color

For configuration options and color palette options, visit the Material 3 Custom Theme Schematic Documentation →
