# Angular Material Enhanced

A modern demonstration application and SCSS design extension illustrating how to utilize **Angular Material component overrides** (`@angular/material`) to customize the look, feel, sizing, corner geometry, and density of Material 3 components.

## What This Demo Illustrates

Angular Material 3 provides powerful official Sass mixins (such as `mat.button-overrides`, `mat.form-field-overrides`, etc.). This project demonstrates a production-grade, systematic methodology to:
1. **Calibrated Sizing Scales**: Uniform heights, touch targets, and font/icon scaling from `xsmall` to `xlarge`.
2. **Geometric Corner Radius**: Seamless switching between fully rounded pills (`sh-round`), proportional squircle corners (`sh-squircle`), and sharp rectilinear forms (`sh-square`).
3. **Semantic Modifiers**: High-contrast `destructive` button and checkbox states adhering to WCAG contrast standards.
4. **Interactive Component Configurators**: Real-time attribute toggling, visual previews, and syntax-highlighted code generation for each Material component.
5. **Full Component Showcase Gallery**: A dedicated overview page displaying every component variation in every size and shape.
6. **One-Click CSS / SCSS Copying**: Autogenerated compiled CSS and SCSS packages ready to drop into any Angular workspace.

## Sizing & Shape Classes

### Sizing Scale (`sz-*`)
- `sz-xsmall`: 24px container height (Buttons, Toggles, Progress Bars, Sliders, Slide Toggles)
- `sz-small`: 32px container height (All components)
- `sz-medium`: 40px container height (Default baseline)
- `sz-large`: 48px container height (All components)
- `sz-xlarge`: 64px container height (All components)

### Corner Radius (`sh-*`)
- `sh-round`: `9999px` border-radius (Capsule / Pill)
- `sh-squircle`: `height / 4` or `8px` proportional rounded rectangle (Default)
- `sh-square`: `0px` border-radius (Sharp box / Rectangular)

### Modifiers
- `destructive`: Error-themed color treatment with active hover and ripple states.
- `no-hint` / `no-error`: Compact form field layout hiding bottom subscript wrappers.

## Components Included

- **Buttons** (`matButton`, `matIconButton`, `matFab`, `matMiniFab`, `extended`)
- **Button Toggle** (`mat-button-toggle-group`, vertical, multiple, icon toggles)
- **Checkbox** (`mat-checkbox`, indeterminate, destructive)
- **Chips** (`mat-chip`, avatars, removable chips, chip grid inputs)
- **Form Field & Radios** (`mat-form-field`, `mat-radio-button`, password visibility toggle, select dropdown, textarea)
- **Progress Bar** (`mat-progress-bar`, determinate, indeterminate, buffer, query)
- **Slider** (`mat-slider`, continuous, discrete with tick marks, range slider)
- **Slide Toggle** (`mat-slide-toggle`, with/without icons)

## How to Use the Overrides in Your Angular Project

### Option A: Using the Compiled CSS
Download or import `material-overrides.css` in your `angular.json`:
```json
"styles": [
  "src/styles.scss",
  "src/material-overrides.css"
]
```

### Option B: Using SCSS Mixins
Include `_mat-overrides.scss` in your main `styles.scss`:
```scss
@use '@angular/material' as mat;
@use './scss/mat-overrides.scss';
```

pnpm run generate:css

# Start development server with SSR / Cloudflare Pages emulation
pnpm run start

# Build for production
pnpm run build

# Run Vitest unit tests
pnpm run test
